I wanted my portfolio to work the way I like to work: start with a plan, write down every decision, and ship in small steps. So I treated it like a product.

## A plan and a decision log

Before any code there was a build plan with phases, a task board, and a decisions log. Every choice got a number, from picking Next.js (D1) to the palette (D14) to this blog (D20). When I change my mind, the log says what changed and why. It's the same habit as a good reconciliation: if you can't trace it, it didn't happen.

## Horizon Night

The colors are a near-black navy with one blue light, close to SAP's brand blue but not the same. Headlines are set in a serif for the finance side and a grotesk for the data side, and numbers use a monospaced face so they line up like a ledger.

## A hero made of my world

The first screen borrows from [Lusion](https://lusion.co), a 3D studio whose site I love. Instead of abstract shapes, mine floats the things I work with: dollar signs, gold coins, charts, a graduation cap and a basketball for Courtside. Move your mouse through them and they scatter, bounce off each other and drift home, and the picture bends like light through a lens.

## Fast and accessible anyway

Motion is easy to overdo, so there were rules:

- Phones and anyone who prefers reduced motion get a still image instead of the 3D scene.
- The 3D code only loads once the page is idle, so the text never waits for it.
- Every page is checked for contrast, keyboard use and screen readers.

The result scores in the 90s for speed on phones and 100 for accessibility.

## Built with Claude Code

I built it with Claude Code, reviewing each change on a preview link before it went live. It works the same way I built Courtside: small branches, a clear plan, and nothing merged until it's right.
